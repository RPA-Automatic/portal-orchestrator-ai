# Cubo Connect Demo Script

Use apenas dados fictícios ou sanitizados. O fluxo deve abrir no command center, criar a tarefa fixa, mostrar o plano de cinco agentes, executar o mock, pausar na aprovação R2, aprovar e encerrar mostrando artefatos e auditoria.

Mantenha a parte executada ao vivo abaixo de três minutos e tenha um resultado determinístico de fallback. Nunca conecte repositórios privados, SAP produtivo, contas pessoais ou tokens durante a apresentação.
